# Код Хэмминга (7,4)

Реализация кода Хэмминга (7,4) в рамках третьей задачи большого домашнего задания по дисциплине «Теория информации и протоколы безопасного обмена данными», 4 семестр, 2 курс, НИЯУ МИФИ.

**Автор:** Максименко Василий

---

## О программе

Веб-приложение демонстрирует работу помехоустойчивого кода Хэмминга (7,4): пользователь вводит 4-битное сообщение, наблюдает процесс кодирования с вычислением контрольных битов, при желании вносит ошибку в любой бит кодового слова, после чего декодер вычисляет синдром, находит позицию ошибки и исправляет её. На каждом шаге показаны формулы и промежуточные результаты.

Код Хэмминга (7,4) добавляет 3 контрольных бита к 4 информационным, образуя 7-битное кодовое слово. Это позволяет автоматически исправлять любую однобитовую ошибку и обнаруживать двухбитовую.
